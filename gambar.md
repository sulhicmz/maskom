# AI Studio Image Generation Prompts for Maskom Website

This file provides a set of prompts to generate images for the Maskom website directly in a tool like Google AI Studio.

**Instructions:**

1.  Open your preferred image generation tool (e.g., Google AI Studio).
2.  For each section below, copy the entire prompt text.
3.  Paste the prompt into the image generation tool.
4.  Generate the image.
5.  Save the generated image with a descriptive name (e.g., `logo.png`, `hero-dashboard.png`).

---

### 1. Main Logo

**Prompt:**

```
A modern and professional logo for a company named "Maskom". The logo should be clean, simple, and easily recognizable. It should represent connectivity, technology, and reliability. The color scheme should be blue (#004BFF) and white (#ffffff). The output should be a high-resolution PNG with a transparent background.
```

---

### 2. Hero Image (Dashboard)

**Prompt:**

```
A futuristic and abstract representation of a secure and reliable global network, with glowing lines connecting different parts of the world on a dark background (#1D1D1D). The image should convey a sense of high technology, connectivity, and security. The primary colors for the glowing lines should be blue (#004BFF) and green (#65FF4B). The image should have a 16:9 aspect ratio and a photorealistic style.
```

### 3. Client Logos (Set of 8)

**Prompt:**

```
A set of 8 fictional, modern, and professional-looking company logos. The logos should be diverse in style and represent companies from different industries (e.g., technology, finance, retail, healthcare). The logos should be in a single color (light gray - #A9ADB9) and have a transparent background. The images should have a 1:1 aspect ratio.
```

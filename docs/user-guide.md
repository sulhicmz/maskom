# Panduan Pengguna Maskom

Panduan ini membantu pengunjung dan pelanggan potensial untuk menavigasi situs web Maskom dan memanfaatkan semua fitur yang tersedia.

## Tentang Panduan Ini

Panduan ini ditujukan untuk:
- **Pengunjung Baru**: Mencari layanan konektivitas dan managed service
- **Pelanggan Potensial**: Ingin membandingkan paket harga dan fitur
- **Pembaca Blog**: Mengikuti artikel dan tutorial teknis
- **Pencari Layanan**: Mengajukan permintaan konsultasi atau support

## Navigasi Situs

### Menu Utama

Situs web Maskom memiliki menu navigasi utama di bagian atas layar:

| Menu Item | Deskripsi | Halaman |
|-----------|-----------|---------|
| **Home** | Halaman utama dengan informasi singkat | `/` |
| **Tentang** | Informasi perusahaan dan tim | `/about` |
| **Layanan** | Daftar lengkap layanan konektivitas | `/services` |
| **Harga** | Paket harga dan rencana berlangganan | `/pricing` |
| **FAQ** | Pertanyaan yang sering diajukan | `/faq` |
| **Blog** | Artikel dan tutorial teknis | `/blog` |
| **Kontak** | Formulir kontak dan informasi | `/contact` |

### Menggunakan Menu

1. **Desktop**: Klik menu di bagian atas
2. **Mobile**: Klik ikon "☰" (hamburger menu) untuk membuka menu
3. **Dropdown**: Beberapa menu memiliki submenu - arahkan kursor untuk melihat opsi

### Breadcrumb Navigation

Saat Anda menjelajahi halaman dalam, breadcrumb akan muncul di bagian atas:

```
Home > Services > Internet Installation
```

Klik breadcrumb untuk kembali ke halaman sebelumnya.

## Memahami Paket Harga

### Halaman Harga

Akses halaman `/pricing` untuk melihat paket harga.

### Tab Harga

Paket harga terorganisir dalam tab:
- **Monthly**: Pembayaran bulanan
- **Yearly**: Pembayaran tahunan (hemat 20%)

### Paket Harga

| Paket | Kecepatan | Cocok Untuk |
|-------|-----------|--------------|
| **Basic** | 100 Mbps | UKM kecil (10-20 users) |
| **Pro** | 500 Mbps | UKM menengah (50-100 users) |
| **Enterprise** | 1 Gbps | Perusahaan besar (200+ users) |

### Fitur Paket

Setiap paket mencakup:

- **Kecepatan Internet**: Sesuai paket
- **Static IP**: Alamat IP statis
- **24/7 Support**: Dukungan teknis sepanjang waktu
- **SLA 99.9%**: Garansi uptime 99.9%
- **Gratis Instalasi**: Instalasi gratis untuk area terjangkau
- **Router Termasuk**: Router WiFi disediakan

### Memilih Paket

1. **Lihat Tab Pilihan**: Pilih Monthly atau Yearly
2. **Bandingkan Paket**: Lihat kecepatan, harga, dan fitur
3. **Pilih Paket**: Klik tombol "Pilih Paket" pada kartu harga
4. **Isi Form**: Formulir konsultasi akan muncul
5. **Kirim Permintaan**: Tim kami akan menghubungi Anda dalam 24 jam

### Tambahan Add-on

Layanan tambahan yang tersedia:

| Add-on | Harga | Deskripsi |
|---------|--------|-----------|
| **Extra Public IP** | Rp 50.000/IP | IP publik tambahan |
| **Dedicated Support** | Rp 500.000/bulan | Support dedicated 24/7 |
| **Bandwidth Upgrade** | Bervariasi | Upgrade bandwidth kapan saja |
| **VPN Service** | Rp 200.000/bulan | VPN untuk karyawan |

## Membaca Blog

### Halaman Blog

Akses halaman `/blog` untuk melihat semua artikel.

### Filter dan Kategori

#### Kategori Blog
- **Konektivitas Terkelola**: Artikel tentang jaringan dan internet
- **Security**: Keamanan jaringan dan data
- **Cloud Computing**: Layanan cloud dan backup
- **Tips & Tricks**: Tips teknis untuk penggunaan jaringan
- **Company News**: Berita terbaru Maskom

#### Filter Sidebar
Gunakan filter sidebar untuk:
- Mencari artikel berdasarkan kategori
- Mencari artikel berdasarkan tag
- Melihat artikel populer

### Membaca Artikel

#### Halaman Artikel

Setiap artikel memiliki:
1. **Judul**: Judul artikel
2. **Meta**: Penulis, tanggal, kategori, tag
3. **Thumbnail**: Gambar artikel
4. **Konten**: Konten artikel penuh
5. **Related Posts**: Artikel terkait
6. **Comments**: Komentar pembaca (jika tersedia)

### Fitur Blog

#### Bookmark Artikel

Simpan artikel untuk dibaca nanti:
1. Klik ikon bookmark (⚪) di bagian atas artikel
2. Ikon akan berubah menjadi terisi (⚫)
3. Artikel tersimpan di browser Anda

#### Bagikan Artikel

Bagikan artikel ke media sosial:
1. Klik tombol "Share" di bagian atas
2. Pilih platform: Facebook, Twitter, LinkedIn, atau Instagram
3. Jendela share akan terbuka

#### Cari Artikel

Gunakan kolom pencarian:
1. Ketik kata kunci di kolom pencarian
2. Tekan Enter atau klik ikon pencarian
3. Hasil pencarian akan muncul

### Berlangganan Newsletter

Dapatkan update artikel terbaru:
1. Gulir ke bagian bawah halaman blog
2. Masukkan email Anda di form newsletter
3. Klik tombol "Berlangganan"
4. Anda akan menerima email konfirmasi

## Mengajukan Permintaan

### Formulir Kontak

Akses halaman `/contact` untuk menghubungi kami.

### Jenis Permintaan

Pilih jenis permintaan:
- **Konsultasi Gratis**: Konsultasi untuk layanan baru
- **Request Demo**: Demo produk layanan
- **Dukungan Teknis**: Masalah teknis atau pertanyaan
- **Penawaran Harga**: Permintaan penawaran khusus
- **Lainnya**: Pertanyaan lainnya

### Cara Mengisi Formulir

1. **Pilih Jenis Permintaan**: Dropdown di bagian atas form
2. **Nama Lengkap**: Masukkan nama Anda
3. **Email**: Masukkan email aktif Anda
4. **No. Telepon**: Masukkan nomor WhatsApp/telepon
5. **Perusahaan**: (Opsional) Nama perusahaan Anda
6. **Pesan**: Tulis pesan atau pertanyaan Anda
7. **Kirim**: Klik tombol "Kirim Pesan"

### Validasi Formulir

Formulir akan memvalidasi:
- ✅ Email harus dalam format yang valid
- ✅ Nama harus diisi
- ✅ Email harus diisi
- ✅ Pesan harus diisi (minimal 10 karakter)

### Setelah Mengirim

1. **Notifikasi Success**: Toast notification akan muncul
2. **Email Konfirmasi**: Anda akan menerima email otomatis
3. **Tindak Lanjut**: Tim kami akan menghubungi dalam 24 jam
4. **Tracking**: Status permintaan dapat ditanyakan melalui email

## Dark Mode

### Mengaktifkan Dark Mode

1. **Klik Tombol Theme**: Klik ikon matahari/bulan di pojok kanan atas
2. **Toggle Theme**: Tema akan berubah menjadi gelap/terang
3. **Preference Disimpan**: Preferensi tema Anda akan disimpan

### Default Theme

- **Light Mode**: Default jika Anda belum pernah mengubah tema
- **System Theme**: Jika Anda mengatur sistem ke dark mode, situs akan mengikuti

### Mengapa Dark Mode?

- **Kenyamanan Mata**: Kurangi kelelahan mata di lingkungan gelap
- **Hemat Baterai**: Menghemat baterai pada layar OLED
- **Estetika**: Tampilan modern dan elegan

## Pertanyaan Umum

### Umum

**Q: Apakah layanan Maskom tersedia di seluruh Indonesia?**
A: Layanan kami tersedia di kota-kota besar (Jakarta, Surabaya, Bandung, Medan, dll.). Hubungi kami untuk cek ketersediaan di area Anda.

**Q: Berapa lama proses instalasi?**
A: Instalasi standar membutuhkan waktu 1-3 hari kerja setelah konfirmasi.

**Q: Apakah ada biaya pemasangan?**
A: Instalasi gratis untuk area terjangkau. Area terpencil mungkin dikenakan biaya tambahan.

### Harga

**Q: Apakah harga sudah termasuk PPN?**
A: Harga yang tertera belum termasuk PPN 11%.

**Q: Boleh upgrade paket di kemudian hari?**
A: Ya, Anda dapat upgrade paket kapan saja tanpa biaya penalti.

**Q: Apakah ada diskon untuk pembayaran tahunan?**
A: Ya, pembayaran tahunan mendapatkan diskon 20%.

### Teknis

**Q: Apakah router disediakan?**
A: Ya, router WiFi disediakan gratis untuk semua paket.

**Q: Berapa jumlah IP statis yang didapat?**
A: Setiap paket mendapatkan 1 IP statis. Bisa tambah IP dengan biaya tambahan.

**Q: Apakah ada garansi uptime?**
A: Ya, kami memberikan SLA 99.9% dengan kompensasi jika tidak tercapai.

### Support

**Q: Bagaimana cara menghubungi support?**
A: Hubungi kami melalui form kontak, WhatsApp, atau email (support@maskom.co.id).

**Q: Jam operasional support?**
A: Support tersedia 24/7 untuk semua pelanggan.

**Q: Apakah ada dukungan onsite?**
A: Ya, dukungan onsite tersedia untuk paket Enterprise.
